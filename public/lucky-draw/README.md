# ภาพพื้นหลังเวทีจับรางวัล

วางไฟล์ชื่อ `winter-night.jpg` ในโฟลเดอร์นี้ แล้วหน้า
`/admin/campaigns/lucky-draw` จะใช้ภาพนั้นเป็นฉากหลังแทนฉากที่วาดเอง
(ท้องฟ้า ภูเขา ทุ่งหิมะ ต้นสน ออโรรา จะถูกปิดทั้งหมด เพราะภาพมีครบอยู่แล้ว)

- อัตราส่วน 16:9 กว้างอย่างน้อย 1920px
- ถ้าไม่มีไฟล์นี้ เวทีจะวาดฉากเองเหมือนเดิม หน้าไม่พัง

ชื่อไฟล์กำหนดไว้ที่ `BACKDROP_IMAGE` ใน
`src/components/admin/lucky-draw/winter.ts`
